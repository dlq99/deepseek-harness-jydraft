# 00 · 代码关注度地图

> **本文件由 `jydraft/scripts/attention-map.mjs` 生成，不要手改。**
> 重新生成：`node jydraft/scripts/attention-map.mjs`

这张图回答一个问题：**哪些代码是我的，哪些是不用关注的。**

分层不是凭印象写的，是从真实数据推出来的：枚举全部叶子包 → 解析各 bundle 的 `cordis.patch.yml`
→ 算出哪些包真的会被挂载 → 再算这些包的依赖闭包（真正会被加载的集合）。

## 一眼看全

| 层 | 是什么 | 包数 | 你要做什么 |
|---|---|---:|---|
| **T0** | 你自己的代码（`jydraft/`） | — | **随便改** |
| **T1** | 你会 `import` 的接口 | 8 | **改这些等于改你的编程接口**，要慎重 |
| **T2** | 影响架构判断的机制 | 13 | **读它、理解它，但不改它** |
| **T3** | 被挂载、但你不碰 | 230 | 知道它在就行 |
| **T4a** | 整组可无视 | 27 | **不用看** |
| **T4b** | 未被任何 profile 加载 | 36 | **不用看** |

合计叶子包 **312** 个，分布在 **54** 个包组。

两个数要分清：

- **直接挂载**（`web` profile 的 bundle 行点名挂的）：**172** 个
- **依赖闭包**（再加上它们的内部依赖 —— 真正会进运行时的集合）：**249** 个（79.8%）

所以 **36** 个包（11.5%）**根本不会被加载**。

> **一个必须说清的点**：这 36 个包是「不加载」，不是「没被引用」——
> 有些是测试支持、有些是备用 provider、有些是还没挂进默认 profile 的能力。
> **它们是候选的「可无视」区，但不是「死代码」区。**

## T1 · 你会 import 的接口

**这八个包是你的编程接口。** 它们的类型定义会出现在你的插件代码里。
改这些等于改你的 API —— 但注意：**你不需要改它们**，你要用的是它们。

| 包 | 目录 | 用来干什么 |
|---|---|---|
| `cordis` | `（vendor）` | 插件框架本身。`Context` 类型、`Service` 基类 |
| `dsh-tools` | `packages/core/tools` | `defineTool` —— 注册工具的唯一入口 |
| `schemastery` | `（vendor）` | `Schema` —— 插件配置的声明式校验 |
| `dsh-agent` | `packages/core/agent` | `Agent` / `AgentRegistry` —— 建会话、跨会话投消息 |
| `dsh-system-prompt` | `packages/core/system-prompt` | `PromptSection` / `PromptContext` —— 注入 |
| `dsh-web` | `packages/web/web` | `WebFetchResult` 等 web 侧类型 |
| `dsh-session` | `packages/core/session` | 会话与事件类型 |
| `dsh-jobs` | `packages/jobs/jobs` | 后台任务（转写、编译要用） |

## 怎么用这张图

### 最有效的一条：只在关心的目录里搜

**这是「太吵」最直接的解法，比排除规则有效得多。**

实测（搜 `agent`）：

| 搜法 | 命中文件 |
|---|---:|
| 全仓库 | 3299 |
| 加 `.rgignore` 排除 T4 | 2207（−33%） |
| **只搜 T1+T2 的 21 个包 + `jydraft/`** | **173（−95%）** |

```sh
# --paths 输出 T1+T2 的目录，直接喂给 rg
rg <pattern> $(node jydraft/scripts/attention-map.mjs --paths)
```

**为什么 scoped 比 ignore 有效**：ignore 只能排掉 T4（36 个包），而 T3 有 **230** 个。
日常你真正要读的是那 **21 个包**，剩下的 291 个不需要出现在搜索结果里。

### 其它查询

```sh
# 只看某一层
node jydraft/scripts/attention-map.mjs --tier 4

# 改某个包之前，先看爆炸半径
node jydraft/scripts/attention-map.mjs --who-depends-on dsh-agent

# 看某个包的完整依赖闭包
node jydraft/scripts/attention-map.mjs --closure dsh-tools

# 列出 web profile 真正会加载的包
node jydraft/scripts/attention-map.mjs --mounted
```

### 全仓库搜索时排除噪声

`jydraft/data/rgignore` 是一份排除规则。**不要改仓库根的 `.rgignore`** —— 那属于 `jydraft/` 之外，会破坏隔离。
用 `--ignore-file` 或环境变量引用它：

```sh
rg --ignore-file jydraft/data/rgignore <pattern>
# 或设一次，之后所有 rg 调用自动生效
export RIPGREP_CONFIG_PATH=jydraft/data/rgignore
```

它**刻意不排除** `docs/` 与 `vendor/` —— 前者是理解框架最该搜的地方，后者是追框架行为时要搜的地方。
把这两个排掉会让「安静」变成「搜不到」。
